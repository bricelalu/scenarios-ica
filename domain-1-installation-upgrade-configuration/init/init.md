# Domain 1: Installation, Upgrade & Configuration (20%)

Welcome to the **Installation, Upgrade & Configuration** domain of the Istio Certified Associate exam. This domain represents **20% of the exam** and covers the fundamental skills needed to deploy and manage Istio service mesh infrastructure.

## Official ICA Competencies Covered

This scenario will teach you the following official ICA competencies:

✅ **Installing Istio with istioctl or Helm**  
✅ **Installing Istio in Sidecar or Ambient Mode**  
✅ **Customizing your Istio Installation**  
✅ **Upgrading Istio (Canary, In-Place)**  

## What You'll Learn

By completing this scenario, you will master:

1. **Installation Methods**
   - istioctl CLI installation with profiles
   - Helm chart-based installation and configuration
   - Comparison of installation approaches

2. **Architecture Modes**
   - Sidecar Mode: Traditional proxy injection
   - Ambient Mode: Sidecar-less service mesh
   - When to use each architecture

3. **Customization Techniques**
   - IstioOperator API for advanced configuration
   - Component customization and resource tuning
   - Multi-cluster installation patterns

4. **Upgrade Strategies**
   - Canary upgrades with revision management
   - In-place upgrade procedures
   - Rollback strategies and best practices

## Prerequisites

- Basic Kubernetes knowledge (pods, services, deployments)
- Understanding of YAML configuration
- Familiarity with command-line tools

## Real-World Context

These skills are essential for:
- **Production deployments** of Istio service mesh
- **Enterprise environments** with specific requirements
- **Multi-cluster** and **hybrid cloud** architectures
- **DevOps workflows** for continuous deployment
